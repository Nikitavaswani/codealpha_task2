Image Gallery Web App

An elegant and responsive Image Gallery Web Application developed as part of the CodeAlpha Internship Program. This project showcases front-end development skills using HTML, CSS, and JavaScript to build an interactive and user-friendly image gallery.

Project Description

This project is a responsive image gallery that displays images in a grid layout. Users can view images in a larger preview with smooth navigation and interactive effects. The design ensures compatibility across all devices.

Features
 Responsive Grid Layout
 Image Preview (Lightbox Effect)
 Hover Effects
 Next & Previous Navigation

 Technologies Used
HTML
CSS
JavaScript
